# 3.0.0 观察版交付说明

本版将原恐慌指数看板重建为市场风险与基金仓位决策系统。客户端 3.0.0、模型 4.0、数据库 6、API 2。Windows 安装版与便携版均内置 Python 引擎，不依赖系统 Python。

## 已实现的范围

- 保留独立基金估值、托盘、设置、自动刷新、中文用户目录和退出流程。
- 核心状态使用三项固定等权压力：5 日下跌冲击、60 日最高收盘价回撤、20 日下行波动。A 股三风格取中位数，港股与基金关联基准各自校准。
- 真实收盘历史回算与上线后实际正式发布分开，旧模型数据留存但不参与新训练、不拼接曲线。缺失的收盘价、开盘价、成交额及交易日均不补造。
- 5/10/20/30/50 日损失事件、期末收益分位数、时间推进训练、50 日标签隔离、校准和发布白名单。
- 超跌、短期过热分别形成观察条件；费用、策略时间外结果、历史可得性和真实观察未通过时关闭操作建议。
- 多批次手工持仓、中文 CSV 预览与保存、基金分红拆分总回报、基准映射、暴露稳定性、252 日收缩协方差及组合约束。
- 公开申赎状态与下一提交日按方向核实；未知成交净值、确认周期、费率或 QDII 日历不转化为精确交易金额。系统不自动下单。
- 后台下载、已有日期续传、失败重试、训练和报告导出；原响应、单位、来源时间及修订记录留在本机。
- 交易日期只显示日期，真实时间戳才显示时分秒；市场概览的分项中位数只展示可解释的历史分位。基金历史所需的 PyMiniRacer DLL 与 ICU 数据随包提供，并由冻结版实际执行 JavaScript 验证。

## 数据和模型验收结论

逐标的数据范围、字段缺项、基金基准、净值复权核验、辅助来源及逐事件统计见交付附件《回测与实网验收.md》《风险模型事件验收.csv》《模型参数与验证.json》。模型说明、来源清单、固定 YAML 参数、锁定 Windows 依赖及源码同时提供。

实网数据共覆盖 17 个市场/基准，其中 15 个可计算当前收盘状态，12 个具备本版完整训练和回放长度；报告包含 180 个期限与跌幅事件组合。11 只公开基金均已取得单位净值并完成分红拆分解析，9 只指数基金核实了具体跟踪基准，2 只主动/混合基金保留未核实映射。恒生互联网科技业和恒生港股通高股息低波动的本次免费源仅有 46 条日线，不能形成三年参考分布。

默认 20 日跌逾 5% 事件中，沪深300 Brier 为 0.2097，基率基线为 0.1845，简单波动近似基线为 0.1816；分数越低越好。这一结果没有证明预测优于基线，不发布该概率。模型未因测试结果失败而反向调参。

本次真实行情研究回放不具备逐日历史发布时间和修订的完整证据，不能宣称通过严格历史时点可得性验收。部分事件的 Brier、校准误差或时间块区间也未达门槛；短历史标的不强行训练。未通过的概率和操作建议不会进入正式展示。当前压力分及真实价格记录与预测是否达标分开显示。

**真实 20 个交易日观察尚未完成。** 客户端只在实际当日收盘数据完整时记录一次观察，不以历史下载、测试夹具或重复刷新补足天数。因此此次 GitHub 发布为观察版预发布，不标记为通过全部上线门槛的稳定版。完成代码和安装包不意味着预测有效性已经得到证明。

## 升级与备份

应用继续使用 `%APPDATA%/fund-and-panic-desktop`。首次从数据库 5 升级到 6 前，通过 SQLite 在线备份保留 WAL 中已提交内容，再创建新表；基金配置和旧记录保留。备份位于用户目录 `backups/`，不进入 GitHub、安装包或报告压缩包。卸载保留用户数据。

旧参数缺少配置哈希或训练输入指纹时拒绝预测。数据修订须重新训练，历史旧口径保留但不混画；当日重训预测与已发布记录冲突时暂停操作建议。设置中的日志路径可用于定位采集类别、来源、超时和退出码。

需要回退时先退出客户端，保留现有数据库 6，再在独立用户目录使用迁移前数据库和旧程序。旧程序不得直接改写版本 6 数据库。
