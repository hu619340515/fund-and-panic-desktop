# 第四版数据来源与可得性

本版只保存可追溯的原始观测，不为补全指数、成交额、宽度或衍生品数据而估计数值。每次抓取应同时保存来源标识、抓取时间、原始响应和失败尝试；日线的 `published_at` 目前不能由公开接口逐条核验，因此标为 `pit_verified=false`，只能用于描述性回算，不能声称严格时间外训练。

## 指数日线与成交额

- 首选东方财富日线接口 `push2his.eastmoney.com/api/qt/stock/kline/get`，请求中固定 `fqt=0`，使用其返回的开高低收和成交额。它是免费公开接口，但非交易所官方发布渠道，网络或字段校验失败会保留失败记录。
- 对中证/A 股指数，东方财富失败后调用中证指数公司的官方 `https://www.csindex.com.cn/csindex-home/perf/index-perf`。适配器逐行核验 `indexCode` 和英文简称；其 `tradingValue` 是**亿元**，按 [AKShare 对该官方接口的字段说明](https://akshare.akfamily.xyz/data/index/index.html)乘以 `100,000,000` 后才写入人民币元。2026-09-12 的小范围实测中，000300、000905、000852、399808、399989、931865 请求 2026-09-01 至 2026-09-11 均返回 HTTP 200；例如 000300 的 `tradingValue=5357.08`，保存为 `535,708,000,000` 元。代码或名称不符时整源拒绝；仅个别日期成交额缺失/为零时保留已核验 OHLC、该日 `amount=null` 并记录缺失日期。
- 最后备用来源是新浪 K 线，经 [AKShare 的 `hk_js_decode` 源码](https://github.com/akfamily/akshare/blob/main/akshare/stock/cons.py) 解码。备用响应的成交量不能换算成成交额，故成交额字段保持空；过热成交项随之不可用，不得由价格或成交量推导。腾讯日线的 `amount` 字段同样是手数，不能作为成交金额。
- 上游偶尔会返回非交易日记录（例如 2010-01-01）。适配器以交易所日历过滤它们并记录 `non_session_rows`，不把假期数据复制、平移或视作有效日线。
- 港股新浪解码结果偶有二进制尾差，例如 `4550.87988` 与同条最低价 `4550.88`。仅对港股指数按两位报价精度规范化后再校验 OHLC，原始响应不改写；其它价格关系错误仍拒绝。
- 交易日采用上交所或香港交易所日历，并记录缺口。香港交易所确认 [2023-09-01 全天停市](https://www.hkex.com.hk/News/Market-Communications/2023/2309012news?sc_lang=en) 和 [2023-09-08 全天停市](https://www.hkex.com.hk/News/Market-Communications/2023/2309083news?sc_lang=en)，这两天从港股缺口中排除并保留公告链接。

## 已登记的行业指数

行业指数只在基金元数据给出**完全相同**的基准名称时可自动选用；包含行业关键词、比例基准和主动基金描述均返回未核验，不产生映射。历史下载从指数**发布日期**截断，绝不把基日回测序列冒充当时可得记录：399808 为 2015-02-10、399989 为 2014-10-31、931865 为 2019-03-20。登记依据为中证指数公司公开材料：

- [中证新能源指数（399808）事实资料](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/399808factsheet.pdf)
- [中证医疗指数（399989）事实资料](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/399989factsheet.pdf)
- [中证半导体产业指数（931865）事实资料](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/931865factsheet.pdf)

指数样本、方法和历史可能调整，行业指数也不应被视为任意基金的必然持仓代理。用户手动确认的基准应携带确认状态与生效日期，和自动映射区分。

## 辅助观测

`fetch_auxiliary()` 分别调用既有免费实时适配器获取：沪深300 QVIX、IF 行情、市场宽度、涨跌停。四项各自带 `state`、来源、上游说明、时间戳、原始快照及错误；任一项不可用不会补值，也不读取历史恐慌分数。

- QVIX 先尝试 300 股指 QVIX，再尝试口径不同的 300ETF QVIX；两者均通过 AKShare 的免费 QVIX 上游，因此结果会注明不是独立上游交叉验证。
- IF 依次尝试新浪、AKShare、mootdx，但只有来源时间戳属于请求交易日且带时分秒的报价才可用；不能以抓取时刻代替来源时间。
- 宽度依次尝试东方财富、腾讯、新浪、mootdx。腾讯报价本身独立，但当前 `fetch_live` 的 A 股代码表来自东方财富，响应中据实标注这一依赖；东方财富的全市场总数与返回条数不一致时会拒绝并继续备用链。
- 涨跌停依次尝试东方财富和选股宝。上游只有抓取时刻而无可核验发布时间时，仍可返回数值观测，但 `timestamp=null` 且带 `unverified_time`；不会伪造为当天来源发布时间。

2026-09-12 实网验收（请求交易日 2026-09-11）：股指 QVIX 分时值为空后，300ETF QVIX 在 14:56:06 返回；新浪 IF 在 15:00:00 返回；东方财富宽度断连、腾讯因其东方财富代码表依赖而失败，新浪宽度成功但时间未核验；东方财富涨跌停成功但时间未核验。所有失败尝试随结果保留。

## 半导体产业指数的历史限制

中证官方 931865 接口在 2019-03-20 至 2023-09-04 的真实响应中只有 `close`、`tradingVol` 和 `tradingValue`，`open`、`high`、`low` 均为 `null`；从 2023-09-05 起才返回完整 OHLC。分年请求 2019、2020、2021、2022、2023-09-04 前的结果相同，并非一次请求的行数限制。适配器保留这些发布日期之后的真实 **close-only** 日线：`open/high/low=null`，并以 `close_only_dates` 标注；绝不以收盘价、成交量或相邻日补造 OHLC。提供了但违反价格关系的 OHLC 仍会拒绝。核心 60 日高点口径为最高收盘价，因此该部分可使用真实 close；是否需要真实开高低由模型层单独决定。实测新浪 `sh931865`、`sz931865` 日线均为无效/404。

## 国证自由现金流的官方历史

国证官网公开接口 `https://hq.cnindex.com.cn/market/market/getIndexDailyData` 可用 `indexCode=980092`、发布日期 `2012-12-28` 至请求日的日期参数返回自由现金流指数日线。适配器请求时带官网 `Origin` 和 `Referer`，并严格核验响应中的 `indexCode=980092`、`indexName=自由现金流`、`indexEName=CNIFCF`。字段表中的 `timestamp` 是 UTC 毫秒，转换为上海交易日；`close` 与可得 OHLC 保留原值，缺失 OHLC 保持空。

该响应含 `amount`，但本次未取得国证官网前端关于该字段币种和单位的可核验说明。因此该数值只保留在原始响应，规范日线的 `amount=null`、`amount_unit=null`，并以 `amount_unverified_dates` 标出；不能用于成交额过热特征。2026-09-12 实测请求 `2012-12-28` 至 `2026-09-11` 返回 HTTP 200；规范化后有 3,327 条日线，首条为 `2012-12-31`、末条为 `2026-09-11`，无拒绝行、无 close-only 行，所有成交额均保持空。该官方源优先于国证自由现金流的通用行情/新浪备用链，失败才继续尝试其它来源。

## 恒生行业指数免费历史边界

`hkHSIII` 与 `hkHSHYLV` 的免费公开行情本次只有有限近期行数（实测约 46 行），不能据此宣称覆盖各自发布日期以来的完整历史。恒生指数公司将较长历史数据列在 [数据订阅目录](https://www.hsi.com.hk/static/uploads/contents/en/products/data_subscription/pdf_eng.pdf)，目录日期为 2026-09-07；本项目不新增付费订阅，也不以合成、回填或其它指数替代这些缺口。报告会如实显示记录范围和缺失状态。

## 交付报告的数据范围

`risk_v4_report.py` 从审计库导出时固定遍历全部已登记标的；没有实际日线的标的仍输出 `缺少真实日线`，不会因缺行情而从报告消失。每个标的同时记录实际日线数据指纹、真实训练与校准截止（如模型产物实际保存）、配置哈希及模型缺项；没有保存训练产物或历史发布时间凭证时保持为空或标为未核实。

报告只读取 `watch_funds` 中的公开六位基金代码及其公开 `fund:<code>` 资料，列示单位净值日期范围、分红/拆分复权完整性、当前公开资料基准映射和缺项。它不读取 `portfolio`，不输出持仓、份额、市值、在途资金、本地数据库路径或原始持仓文件。辅助观测逐项列明 QVIX、IF、宽度、涨跌停的来源名称、上游、请求交易日、来源时间核验和缺项；来源没有可核验发布时间时报告保留 `timestamp=null` 与相应标志。

逐事件 CSV 使用中文表头，并列实际模型 Brier、训练基率 Brier 和简单波动基线 Brier；任何上游模型未提供的字段均为空。JSON 保留策略的 `selection_rule`、`baseline` 的开发/留出段净收益、最大回撤、换手率，以及候选网格的 `development_selection_score` 和 `development_drawdown_improvement`，供复核开发段固定指标；这些记录不改变概率发布门槛。
