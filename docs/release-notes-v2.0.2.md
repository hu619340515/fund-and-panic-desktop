# 2.0.2：补全真实历史行情与历史估计曲线

- 修复 API 读取精简聚合表造成的漏字段：QVIX 昨收、5 分钟前及成交额历史基准按同一时间的完整原始记录返回，不借用其他时点。
- 下载上证 A 股指数和深证 A 股指数的历史成交额，合计得到沪深 A 股市场成交额，使用最近 20 个已完成交易日中位数。单位为元，不把沪深300成份股成交额当作全市场。按日期范围增量缓存。
- 新增“补全历史”按钮：读取真实沪深300日线、沪深 A 股成交额和 300ETF QVIX 历史，逐日回算近一年历史估计；只使用该日及更早数据，不使用未来数据。
- 历史估计采用既有日线特征与权重，对可用组件重新归一化；缺少的历史市场宽度、IF 基差等不填零、不用今天的数据替代。界面显示缺项及覆盖率，以绿色虚线与正式收盘值区分。
- 历史估计单独持久化，不写入正式收盘表，不参与正式/实时指数历史校准。重新启动后可直接读取已回算记录；下载失败保留已有结果。

使用方法：退出旧版本，启动 2.0.2；在“近一年收盘与历史估计”区域点击“补全历史”。QVIX 和成交额基准随下一次成功实时刷新更新。午休或非交易时段保持既有行情，不制造新盘中记录。

免费接口有缺失时，历史估计不等于完整模型的正式指数；“导出正式收盘”仍只导出正式记录。

实网曾取得242条历史估计，覆盖率45%–55%；最终复测期间东方财富接口出现断连，空目录首次下载可能失败。此时界面显示错误，可稍后重试，已经回算的记录继续保存在本机。详见[验收记录](verification-v2.0.2.md)。

新增接口：`GET /api/v1/history`、`POST /api/v1/history/refresh`；原有正式收盘接口不改变。数据库继续使用 V5，增加独立历史估计表，不改写原有用户记录。

来源参考：[AKShare 指数历史接口](https://akshare.akfamily.xyz/data/index/index.html)、[QVIX 源码](https://github.com/akfamily/akshare/blob/main/akshare/index/index_option_qvix.py)。
