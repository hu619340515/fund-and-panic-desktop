## 数据与方法

- 实网取得 500 自然日范围内 335 个交易日的沪深300日线，以及上证 A 股指数/深证 A 股指数的共同日期成交额。成交额字段为东方财富 f57，单位人民币元，不能与成交量（手）混用。
- 最近20个已完成交易日成交额中位数约 2.0185 万亿元；两市必须同时具备同日数据。当前日期及未来日期均排除。
- 近一年回算得到 242 条历史估计（2025-09-11 至 2026-09-10）。按既有日线特征、固定锚点和组件权重计算，只对有输入的特征/组件归一化；可用特征权重覆盖率为45%–55%。历史全市场宽度与IF基差未取得，保持缺项，不能等同于正式指数。
- 历史回算按日期前推，用此前收益率估计波动率基线，校准只用此前历史估计；不读取未来日期，也不影响实时或正式模型校准。
- 完整原始盘中 JSON 和精简聚合表按交易日、时间戳连接，恢复 QVIX 昨收、5分钟前和20日成交额基准等字段；旧记录真正缺失仍为空。
