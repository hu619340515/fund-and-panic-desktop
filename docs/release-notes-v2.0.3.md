# 2.0.3：接入中金所 IF 与开盘红历史宽度

- 历史补全新增中金所官方 IF 合约日线，按当日具体合约收盘价计算近月、次月年化基差与期限结构；沿用现有公式和权重。
- 新增开盘红历史上涨、下跌、平盘、涨跌停家数。已有宽度特征独立参与估计，不再因缺少收益中位数而整组缺失。
- 精确收益中位数、跌幅≥5%和≥7%占比仍保持缺项；不把未确认边界的分桶转换为精确数值。历史估计与正式收盘值继续分开。
- 历史图表增加各来源成功天数及市场口径说明；网络失败保留已有记录，并记录具体来源与失败原因。
- IF 按月、市场宽度按日缓存，重试复用已成功的数据。首次补全可能需要数分钟，最多等待5分钟。

使用方法：从托盘退出旧版本，运行2.0.3，在近一年图表点击“补全历史”。新版继续使用原有用户目录，不清空基金配置、数据库或缓存。实时行情模块不会用历史估计代替实时数据。

免费接口可能限流或缺少个别日期。覆盖率表示当前已取得输入的模型权重比例，不代表预测准确率；宽度采用开盘红统计口径，不能视为已经与逐股统计完全一致。

来源和实测证据见[接口核验记录](https://github.com/hu619340515/fund-and-panic-desktop/blob/v2.0.3/docs/history-source-investigation-2026-09-11.md)。

最终便携版实測回算242个交易日，IF与宽度各覆盖242天，模型输入权重覆盖率约74%–84%。通过缓存重算、重启恢复、中文路径、无系统Python与退出无残留验收；详细条件见[验收记录](https://github.com/hu619340515/fund-and-panic-desktop/blob/v2.0.3/docs/verification-v2.0.3.md)。
