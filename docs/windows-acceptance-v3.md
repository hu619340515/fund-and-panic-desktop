## 最终便携版实网

运行 `node packaging/smoke-live.cjs desktop/dist/FundAndPanic-Portable-3.0.0-x64.exe`，使用新的隔离中文用户目录，未复制用户数据库。通过如下实际链路：

- 内置 EXE 获取沪深300、中证500、中证1000 的真实历史，三个状态截止日均为 2026-09-11，市场概览中位数可用；来源、时间、缺项和质量状态实际渲染后截图。
- 公开测试基金 013273、021458、012414 正常加入自选；风险下载期间基金估值可独立刷新，健康服务保持连接。
- 从该便携版生成的 SQLite 读取 021458 在 2024-11-11 的每份分红 0.016 元、012414 在 2021-09-07 的每份分红 0.012 元，与当天及前次真实单位净值核对复权公式，误差小于 1e-10。
- 未获发布资格的概率保持隐藏；退出后引擎进程已回收。

最初实网验收发现 PyMiniRacer DLL 漏包，随后显式补齐 DLL 和 ICU 数据，并增加冻结版 JavaScript 真执行预检；上述结果来自修复后重新构建的最终 EXE。未使用开发 Python 的成功结果替代便携版实测。

17 个市场/基准、180 个事件组合和 11 只公开基金的完整实网研究结果另见[数据与模型报告](verification-v3.0.0.md)。两项较短的港股行业历史及不可核验的辅助来源时间仍按缺项显示。
