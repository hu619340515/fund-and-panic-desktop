## 数据与缓存

中金所历史按月份缓存，下载未完成月份时 `complete=false`，跨月必须再下载一次才可长期复用。交割日仅由完整月份的官方合约终止记录推导，并校验合理范围。

开盘红按日期缓存原始公开响应，最多4个并发请求；总截止时间到达后返回已成功日期和具体错误。分桶未用于构造精确跌幅阈值或收益中位数。界面标明上游宽度统计口径。
